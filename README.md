# Jarvis

Jarvis is a private, cloud-backed personal assistant. Version 0.1.0 establishes the Worker workspace and cloud-core foundation.

See [TESTING.md](TESTING.md) for local verification commands.

The credentialed voice release gate is prepared as an offline-safe contract. Its default command cannot place calls; see [docs/runbooks/voice-smoke.md](docs/runbooks/voice-smoke.md) for authorization prerequisites, redacted evidence, cleanup, and rollback ownership.
