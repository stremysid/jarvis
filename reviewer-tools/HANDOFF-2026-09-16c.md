## Merge tooling (in reviewer-tools; set RELAY_SCRATCH first)

- **`merge-cleared.sh <pr> <branch> <reviewed-sha> <entry.md>`:**
  - posts the clearance entry at the top of AGENT_LOG;
  - merges `origin/main`, resolving AGENT_LOG-only conflicts by prepending branch entries (`agentlog-merge.mjs`);
  - checks the non-log diff equals the reviewed diff by zero-context patch-id;
  - pushes, merges with `--match-head-commit` (with retries), and verifies the main tree equals the merged head.
- **`GATE=<checkout>`** runs the full suite on the exact merged tree before pushing. **Use it for every code PR.** Merging onto a moved main silently breaks the migration lists in `remote-d1-migration-syntax.test.ts` and test-support helpers.
- **`ALLOW_CONTEXT_ONLY=1`** accepts a builder's conflict resolution only when every file's `--numstat` is identical.
- **Non-log conflicts** abort the script. Send a fresh builder a merge-only prompt (`prompts/pr59-mergemain-prompt.txt`).
- **`agentlog-top.mjs <AGENT_LOG> <entry.md>`** puts an entry first, CRLF-safe.
