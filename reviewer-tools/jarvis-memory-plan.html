What Jarvis will do

  1. Keep every conversation.Nothing gets thrown away for being unimportant.
  2. Remember what matters on its own.You don't manage anything. Important things come back up when they're useful.
  3. Find anything you ask about, even small things.It searches everything you've ever said, not just the important parts.
  4. Say when it's guessing.It never passes a guess off as fact.
  5. Keep it organized like a brain.Memories get filed into a tree: main areas like St. Remy, then sub-areas like the website and the PC app, and deeper. Jarvis does the filing.

Decided for you

  • Memory lives in the cloud where Jarvis already runs, so it works with every PC off. No new computer and no Linux server.
  • You said yes to a private GitHub copy of Jarvis's memory, as notes Obsidian can open. It's built after the main memory works, and it leaves out health, money, passwords and other people's details. Later you'll click once to give it access to that one repo.
  • You never have to open Obsidian. You can check or fix memories just by asking Jarvis, like "why do you think that?"
  • "Forget that" hides the memory from Jarvis. Fully erasing things can come later if you want it.
