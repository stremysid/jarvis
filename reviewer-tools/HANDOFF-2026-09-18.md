## 4. Two production defects found today, and how

Both were found by refusing to guess, and both were invisible to a green local suite:

1. **PBKDF2 600,000 iterations** is rejected by the production Workers runtime (cap 100,000); Miniflare has no such cap, so 5,000 local tests passed while the owner passphrase could never be created. Fixed in #89 by six chained passes of 100,000, with a source-scan guard that fails if any `deriveBits` call exceeds the cap (verified by mutation).
2. **`_cf_KV`** above.

The method that worked, twice: eliminate candidates with evidence (replay the writes on a throwaway remote D1, re-run the suite with production-shaped ids, measure CPU), then — with Sid's explicit approval each time — deploy a build that logs the error the code deliberately redacts, read it, and roll back immediately. Both rollbacks were verified.
